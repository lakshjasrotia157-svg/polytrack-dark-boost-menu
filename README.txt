Dark Boost Menu - PolyTrack PML prototype
Target: PolyTrack 0.6.3

This package creates a dark neon-green overlay with Speed and Jump toggles.
IMPORTANT: The toggles are UI-only and do not yet change game physics. A compatible
PolyTrack physics hook/mixin must be added to implement real speed and jump boosts.

To import via PolyModLoader, the folder must be hosted in a supported GitHub/Codeberg
repository and imported using the PolyModLoader CDN URL format. This ZIP is the source
package, not itself an import URL.
